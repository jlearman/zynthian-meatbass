# zynthian-meatbass

Karoryfer Meatbass for Zynthian

This sample library is an upright bass plucked (pizzicato) intended to be suitable for
jazz/blues/bluegrass/Americana on [Zynthian](https://zynthian.org).
It's a reduced version of Karoryfer Meatbass, which is available free at
https://shop.karoryfer.com/pages/free-samples .
While it's intended for Zynthian, it should be fine on any player that supports SFZv2,
including Sfizz and Aria/Sforzando.

This version was reduced from the original by Jeff Learman.

Notes above SPN C5 (an octave above Middle C) are common noises made on the bass,
such as percussive slaps.

## Original README for Karoryfer Meatbass

Meatbass is a sample library for Plogue Sforzando version 1.845 or newer. It contains samples of a 1958 Otto Rubner double bass played and mapped by Drogomir Smolken, recorded by Ludwik Zamenhof.

Fifths tuning (CGDA), Thomastik-Infeld Spirocore strings. F.G. Pfretzschner bow, Pops' rosin.

Pizzicato - plucked notes with four velocity layers and four round robins, percussive noises with round robins also included above the notes

The detune and width controls only affect the sound when 3 or 6 voices are selected. The glide control affects glide time when one of the monophonic mappings is selected - it has no effect on the poly mappings.
